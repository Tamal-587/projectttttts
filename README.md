# 🚀 TaskFlow — Project Management Tool

TaskFlow is a modern full-stack project management application designed to help teams organize projects, manage tasks, assign responsibilities, and collaborate efficiently.

This project was developed as part of the **CodeAlpha Full Stack Development Internship Program**.

---

## ✨ Features

### 🔐 Authentication
- User registration
- Secure login
- JWT-based authentication
- User profile / current-user authentication
- Protected application routes

### 📁 Project Management
- Create and manage projects
- Organize work by projects
- Team/workspace-based organization
- Project members and access management

### 📋 Task Management
- Create new tasks
- Assign tasks to team members
- Change task status
- Set task priority
- Organize tasks using a Kanban board
- Search and filter tasks
- Task details and activity

### 💬 Collaboration
- Add comments to tasks
- Communicate within task discussions
- Community feed
- Create posts
- Like posts
- Comment on posts

### 🎨 User Interface
- Modern dashboard
- Kanban-style task board
- Responsive interface
- Search and filtering
- Clean and professional design
- Interactive task management
